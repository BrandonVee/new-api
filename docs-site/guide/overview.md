# 功能指南概述

开明能源 Token 中转站为用户提供统一的 AI 模型调用入口。普通用户管理 API 密钥、查询用量和账户权益；管理员维护上游渠道、模型、用户与平台配置。

## 系统主页

打开管理员提供的平台地址。未登录时可按站点设置查看首页、模型价格、公告与文档；登录后进入控制台。首页内容和导航由管理员配置，本文档不提供或假定正式平台域名。

![用户应用通过平台访问上游模型的关系图](/images/service-map.svg)

## 角色与权限

| 角色 | 日常职责 | 权限边界 |
| --- | --- | --- |
| 普通用户 | 调用模型、管理自己的密钥、日志、钱包和资料 | 仅访问授权给自己的资源 |
| 管理员 | 管理渠道、用户、兑换码、订阅与模型等 | 按角色及细粒度授权执行，不代表拥有全部系统设置权限 |
| Root／超级管理员 | 系统设置、身份验证、插件与系统维护 | 修改会影响整个平台，应先备份并验证 |

菜单是否可见不能替代服务端授权。遇到无权限提示，应申请对应授权，不要借用其他人的账户或密钥。

## 如何查找功能入口

控制台常用入口包括“概览”“数据看板”“API 密钥”“使用日志”“任务日志”“钱包”“个人资料”和“安全与访问”。管理员还可看到渠道、模型、用户等管理入口。侧栏可配置，名称也可能随界面语言变化。

路径写为 `/keys` 等相对路径时，表示在**平台地址**下打开，而非当前文档站地址。没有入口时先核对登录账户、权限及侧栏设置，再联系管理员。
