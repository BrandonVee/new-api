# 兑换码管理

::: warning 管理员权限
仅限具备兑换码管理权限的管理员。兑换码代表可领取权益，生成、导出与发放都应受控。
:::

## 创建与发放

1. 打开“兑换码”（平台 `/redemption-codes`），选择创建。
2. 按页面填写名称、额度、数量与期限等支持的字段，核对额度单位和总发放规模。
3. 保存后检查生成结果，按授权范围发放。
4. 保管导出文件，不要把未使用代码放到公开文档或截图。

## 查询与停用

按名称、状态或实际可用条件查找记录，核对是否已兑换及相关信息。发现误发或泄露时，在尚可操作的状态下停用或删除，确认结果并检查已发生的兑换。

删除或停用未兑换代码不等于撤回已到账权益。需要调整账户权益时按用户管理流程处理，保留原因和相关记录。

## 处理兑换失败

先核对代码是否完整、已用、过期或停用，再检查账户和接口返回。用户只应向管理员提供必要的兑换记录，不要在公共群中贴出完整代码。

用户端操作见 [钱包与兑换](/user/wallet#充值与兑换)。
