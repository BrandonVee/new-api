# 订阅计划管理

::: warning 管理员权限
仅限具备订阅管理权限的管理员。计划影响用户权益和支付配置，修改前核对在用计划与相关订单。
:::

## 创建计划

打开“订阅”（平台 `/subscriptions`），按当前表单填写计划名称、价格、有效期、额度及分组等可用项目，确认单位、周期和购买限制。

当前项目在支付网关相关合规条款未确认时锁定计划创建与变更。先由有权限的管理员完成对应设置；不要绕过页面和服务端限制。

使用 Stripe、Creem 等支付方式时，按页面要求在支付平台建立产品并填写相应 ID。不要把测试产品或测试凭据用于正式销售。

## 上线前验证

1. 用测试账户核对展示名称、价格、单位和权益说明。
2. 在支付方式允许的测试环境核对下单、支付回调和权益到账。
3. 验证有效期、重置周期和分组效果符合计划配置。
4. 开放前确认用户可理解如何使用、续购及处理订单异常。

本指南不假设所有支付方式都支持自动续费、叠加或退款；以平台实际配置和支付服务能力为准。

## 调整与停用

修改前确认是调整未来售卖，还是会影响已生效订阅。对在用权益、历史订单与支付平台记录分别核对，避免把下架计划理解为自动退款或撤销所有订阅。

费用与权益的基本区分见 [定价、额度与订阅](/console/pricing)，用户阅读 [钱包与订阅](/user/wallet)。
