# 模型管理

::: warning 管理员权限
仅限具备模型管理权限的人员。模型展示、路由和定价分别维护，完成其中一项不代表模型已经可用。
:::

## 维护模型信息

打开“模型”（平台 `/models/metadata`），按界面维护模型名称、供应商、说明和能力等支持的元数据。名称应与实际调用和路由约定保持一致，能力说明需经过对应渠道验证。

## 开放一个模型的顺序

1. 在渠道中配置上游、模型与可用分组，完成渠道测试。
2. 如果使用别名，配置明确的模型映射，见 [模型路由](/console/routing)。
3. 核对模型展示信息和价格设置，明确单位与适用范围。
4. 为测试用户开放对应分组及 API 密钥权限。
5. 使用用户密钥发起实际请求，检查命中渠道、用量与最终记录。

## 修改与下线

调整名称或映射前查明调用方是否依赖原名称。更换上游时测试文本、流式及实际使用的多模态能力，不以同名推断行为相同。

下线前确认是否存在在途任务和依赖应用。仅删除展示信息，不代表相关渠道不再路由；应核对实际路由与权限配置。

用户如何选模型见 [模型广场](/user/models)。
