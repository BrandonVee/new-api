# 高级系统配置

::: warning Root／部署维护权限
运行环境配置可能影响全站。仅由 Root 或授权部署维护人员执行，先备份配置并准备恢复方法。
:::

## 分清配置所在位置

| 类型 | 修改位置 | 生效检查 |
| --- | --- | --- |
| 业务开关、站点内容 | 控制台系统设置 | 保存后以相应角色验证 |
| 数据库、Redis、会话密钥、可信代理等 | 部署环境变量或部署配置 | 确认进程加载，必要时按部署方式重启 |
| HTTPS、超时、上传大小 | 网关前的反向代理或入口层 | 验证真实请求链路 |

改 `.env` 文件不等于运行容器已经读取新值。环境变量是否可热更新应逐项确认，不能假定所有设置保存后立即生效。

## 变更步骤

1. 记录当前版本、配置与依赖，备份需要的数据。
2. 确定影响范围，只修改本次需要的配置。
3. 按部署方式应用变更，观察启动与健康检查。
4. 验证登录、模型请求及受影响的后台任务。
5. 异常时恢复原配置，保留脱敏诊断记录。

不要在工单或截图中暴露数据库密码、会话密钥、上游密钥或支付凭据。
