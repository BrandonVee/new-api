# 自定义 OAuth 提供程序

::: warning Root 权限
仅由有权管理身份验证的 Root／超级管理员配置。此页说明管理操作，不修改认证实现，也不保证所有第三方身份服务都兼容。
:::

## 准备信息

在身份提供方创建应用，取得其文档要求的客户端标识、客户端密钥及相关端点。确认平台对外地址、HTTPS 和回调地址与实际部署一致。

## 配置步骤

1. 进入“系统设置” → 身份验证 → “自定义 OAuth”（平台 `/system-settings/auth/custom-oauth`）。
2. 按当前表单填写名称、客户端配置、授权／令牌／用户信息端点，以及支持的用户字段映射等项目。
3. 将页面或平台要求的回调地址准确登记在身份提供方，不要自行猜测路径。
4. 按提供方说明设置权限范围，保存后用专门的测试账户验证。
5. 验证首次授权、已有账户登录、取消授权及失败提示，确认身份映射正确后再开放。

使用内置 GitHub、Discord、OIDC 等集成时，到相应配置区设置，不要重复创建同一入口。

## 避免把自己锁在平台外

开放前保留经过验证的管理登录与恢复方式。身份服务不可用或配置错误时，不要反复修改多项配置；先核对回调地址、端点、客户端状态与脱敏错误。

客户端密钥、授权码、访问令牌和完整回调查询参数不应出现在公开文档或支持材料中。用户端操作见 [注册与登录](/user/auth)。
