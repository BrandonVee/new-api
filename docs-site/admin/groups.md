# 分组管理（集团管理）

::: warning 管理权限
仅限具备对应用户、渠道或配置权限的管理员。参考材料中的“集团管理”在本项目按用户分组解释，不表示已有企业组织或租户管理模块。
:::

## 分组用于什么

分组连接用户的可用范围、API 密钥所选分组及上游渠道，也可能影响适用价格。分组不是登录角色，调整分组不应顺带提升用户管理权限。

## 配置顺序

1. 确定分组名称、用途、允许的模型与适用价格。
2. 在渠道配置中加入对应分组，并测试模型可用性。
3. 按用户与系统的分组配置，开放用户可选范围。
4. 创建或调整 API 密钥，选择授权分组。
5. 用普通用户验证模型列表与实际调用，检查命中渠道和价格记录。

## 排查分组不可用

| 检查对象 | 核对项 |
| --- | --- |
| 用户 | 所属分组与可用分组是否满足要求 |
| 密钥 | 请求实际选中的分组与限制 |
| 渠道 | 是否启用，并包含目标分组及模型 |
| 定价 | 该分组下的配置是否完整且单位正确 |

改用户分组不会自动替你修改所有渠道。更名前应检查用户、密钥、渠道和价格配置中的引用，避免局部修改导致中断。

更多说明见 [用户、分组与权限](/console/users) 和 [模型映射与路由](/console/routing)。
