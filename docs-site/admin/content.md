# 文档与关于页面配置

::: warning Root 权限
站点内容与入口由具备系统设置权限的 Root／超级管理员维护。当前文档站部署不会自动更新线上控制台配置。
:::

## 配置站点名称与内容

进入“系统设置” → 站点 → “系统信息”（平台 `/system-settings/site/system-info`），按可用字段维护系统名称、Logo、首页内容、关于内容和页脚。

将站点名称设置为“开明能源 Token 中转站”。Logo 应使用经授权的正式资源；本指南未假定附件中的上游标志属于开明能源。保留原始版权、第三方许可与要求的署名。

## 设置文档链接

1. 按 [文档站部署](/deploy/documentation) 发布静态产物，确认正式访问 URL。
2. 在系统信息中的文档链接（`general_setting.docs_link`）填写该 URL；同站托管也可使用 `/manual/` 等路径。
3. 保存后分别在未登录、普通用户与管理员状态下点击文档入口。
4. 验证手机访问、深层页面与搜索，确认没有跳回平台首页。

当前项目默认的 `/docs` 路由会跳转首页。要使用独立文档站，应配置文档链接，不能仅上传文件就假定平台已接入。

## 公告、导航与关于页面

按站点设置维护公告、顶部导航和侧栏模块；聊天入口等内容在对应内容设置中维护。确认目标链接可访问，并避免将内部管理入口公开给普通用户。

首页或关于内容支持的格式以表单说明为准。使用外部页面或资源时先核对来源、权限与移动端表现。

## 发布后检查

核对站点名称、链接、联系方式与实际服务一致；使用长标题和窄屏检查排版。正文、示例和截图不得包含真实密钥、个人资料或内网地址。
