# 站点与系统设置

::: warning 权限与入口
系统设置原则上由 Root／超级管理员或具备相应授权的人员维护。入口：平台 `/system-settings/site`。
:::


站点展示、业务开关和运行配置属于不同层次。修改前先确认配置存在哪里、何时生效、影响哪些用户。

## 在控制台设置的内容

当前项目的系统设置按功能组织，包括站点展示、访问与安全、模型和渠道相关策略、维护与日志等。可用项目取决于管理员权限和部署版本。

修改名称、标志、首页内容、导航或公告后，检查桌面与手机显示，以及未登录访问时的效果。品牌名称使用开明能源 Token 中转站，同时保留项目许可要求的署名与上游链接。

## 环境变量与控制台选项

数据库连接、会话密钥、可信代理和部分超时设置通过进程环境配置。控制台修改某个显示选项，不会自动修改 Docker 的环境变量。

反过来，编辑 `.env` 文件也不代表容器已经加载新值。需要确认 Compose 的传入方式，并按变更内容重建容器或重启服务。

## 改动流程

1. 记录当前值与修改目的，避免一次变更多个无关设置。
2. 检查影响范围，如全站、用户、模型、渠道或分组。
3. 保存后用普通用户和管理员分别验证相关流程。
4. 观察错误与审计记录，确认变更确实生效。
5. 发现异常按原配置恢复，并保留排查信息。

## 文档入口

本项目当前 `web/src/routes/docs.tsx` 会跳转首页，不能把独立文档站当成已经嵌入控制台的页面。部署本手册后，在系统设置的文档链接（`general_setting.docs_link`）填写正式 URL 或 `/manual/` 等站内路径；需要改变默认路由时，应作为单独的控制台改动完成验证。

本次文档站源码不自动修改你的线上站点配置，也不虚构已经存在的正式文档域名。
