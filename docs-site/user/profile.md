# 个人资料与安全

个人资料用于维护账户偏好；“安全与访问”用于管理密码、绑定、会话和验证方式。两者在当前控制台是不同入口。

## 修改个人资料

进入“个人资料”（平台 `/profile`），检查账户信息，并按页面提供的选项调整资料、界面语言及偏好。平台启用签到时才会显示签到功能；侧栏配置也受账户权限限制。

设置额度提醒时确认通知方式可用。提醒是辅助通知，不代表系统会允许超出余额或限额继续调用。

## 管理安全设置

进入“安全与访问”（平台 `/security`），按实际开放的功能操作：

| 区域 | 操作与注意事项 |
| --- | --- |
| 密码 | 按提示完成验证并修改，避免与其他网站共用密码 |
| 账号绑定 | 确认第三方身份后绑定或解绑，保留可用的登录方式 |
| Passkey | 在可信设备创建，按设备提示完成验证 |
| 双重验证 | 完成绑定验证，妥善离线保存恢复凭据 |
| 登录会话 | 检查设备，撤销陌生或不再使用的会话 |
| 访问令牌 | 仅为需要的管理自动化创建，不能替代模型 API 密钥 |

## 设备丢失或凭据泄露

1. 从可信设备登录，撤销异常会话。
2. 检查并处理密码、Passkey、第三方绑定等相关登录方式。
3. 若应用 API 密钥也可能泄露，在“API 密钥”单独停用并轮换。
4. 检查近期日志、钱包变动与管理操作，向管理员提供脱敏后的时间和记录标识。

不要把密码、一次性验证码、恢复码、完整 API 密钥或登录 Cookie 发给支持人员。

::: warning 账户注销
注销属于敏感操作。操作前处理需要保留的资料与业务调用，阅读页面说明，不要把注销当成普通退出登录。
:::
