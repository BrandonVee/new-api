# 任务管理

图像、视频等异步能力可能需要提交任务并等待后台执行。普通用户跟踪自己的任务；插件安装与渠道配置属于管理员职责。

## 提交前检查

确认模型、输入文件或资源地址符合该能力的要求，检查账户权益和密钥限制。不同模型的参数、文件要求及结果类型不同，请按对应接口说明填写。

## 提交与查询

1. 从支持的客户端或 API 提交，保存返回的**网关任务 ID**。
2. 在“任务日志”查询，或按 [异步任务 API](/api/tasks) 使用对应查询接口。
3. 任务未结束时按合理间隔继续查询，终态后停止轮询。
4. 成功后及时读取或保存有权使用的产物；失败时记录错误信息。

## 超时与失败

| 情况 | 处理方法 |
| --- | --- |
| 客户端超时，状态未知 | 用已返回的 ID 查询；没有 ID 时先核对日志 |
| 已排队或执行中 | 等待并查询，不直接重复提交 |
| 任务失败 | 查看原因，修正参数或联系管理员，再决定是否重新提交 |
| 结果链接失效 | 确认存储与保留策略，联系管理员查询是否可恢复 |

不同插件不一定支持取消、删除、重试或永久保存结果。仅使用页面或接口明确提供的操作，不要把删除列表记录当作上游取消。

管理员排查插件与轮询问题见 [任务与插件](/console/tasks)。
