# API 密钥

API 密钥（也称 API 令牌）供应用调用模型。它与网页登录密码、管理访问令牌和上游服务商密钥不同。

## 创建密钥

打开“API 密钥”（平台 `/keys`），选择创建，按用途填写：

| 设置 | 建议 |
| --- | --- |
| 名称 | 按应用和环境区分，如 `knowledge-base-test` |
| 有效期 | 测试设置短有效期，生产按维护周期安排轮换 |
| 额度 | 为单个应用设定预算，仍受账户权益约束 |
| 分组 | 选择管理员已授权且有可用模型的分组 |
| 模型限制 | 只开放应用实际需要的模型 |
| IP 限制 | 填写实际调用出口，代理环境需先确认来源地址 |

保存后，按页面允许的方式复制密钥。已有密钥的查看可能要求额外验证，以页面提示为准。

## 验证可用性

在可信环境用该密钥查看模型列表，再完成一次小规模调用，操作见 [使用 API](/user/playground)。成功后到“使用日志”确认模型、时间和用量。

密钥设为无限额度不代表账户余额无限，也不会取消模型限制、分组授权或上游限流。

## 交给应用使用

服务端应用从环境变量或密钥管理服务读取密钥。每个应用、每个环境使用独立密钥，不要写入公开仓库、浏览器前端包或截图。

## 停用与轮换

正常轮换：创建新密钥 → 更新调用方 → 验证请求与日志 → 停用旧密钥。密钥泄露时立即停用并查异常用量，再为可信调用方重新配置。

无法调用时依次检查密钥状态和有效期、密钥额度、账户权益、分组与模型限制。完整限制说明见 [令牌管理参考](/console/tokens)。
