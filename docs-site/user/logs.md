# 日志与异步任务

使用日志记录调用结果，任务日志记录需要后台处理的任务。请求已提交不等于任务已完成。

## 查找一次调用

1. 打开“使用日志”（平台 `/usage-logs/common`）。
2. 按实际可用的时间、模型或密钥条件缩小范围。
3. 找到对应记录，核对状态、耗时、用量与费用信息。
4. 需要排障时记录时间、模型、请求标识及错误摘要，隐藏凭据。

普通用户仅能查看自己被授权的数据。管理员可见的渠道和诊断字段可能更多。

## 跟踪异步任务

打开“任务日志”（平台 `/usage-logs/task`），找到任务标识及当前状态；绘图类记录可能使用单独视图。等待任务进入成功、失败等终态，再查看结果或错误。

![提交、查询、等待和读取任务结果的流程](/images/task-flow.svg)

如果任务仍在排队或处理中，先查询状态，不要因为客户端等待超时就反复提交。更多说明见 [任务管理](/user/tasks)。

## 怎样理解耗时和费用

首字延迟、总请求耗时、后台任务耗时并不相同。流式中断或异步结算也可能导致记录稍后更新，核对费用时以最终结算信息为准。

## 联系管理员时提供什么

提供时间范围、接口、模型、请求或任务 ID、错误摘要及可复现步骤。不要提供完整密钥、Cookie、验证码、私有结果下载链接或含敏感内容的完整请求包。
