# 注册与登录

使用管理员提供的平台地址登录。账号密码、第三方登录及 Passkey 是否开放，由平台的身份验证设置决定。

::: info 入口
登录：平台 `/sign-in`。注册：平台 `/sign-up`。首次使用请先确认平台是否允许自行注册。
:::

## 账号密码登录

1. 在平台首页选择“登录”，输入用户名或邮箱及密码。
2. 按页面要求阅读并同意用户协议、隐私政策；如出现人机验证，完成验证。
3. 提交登录。已启用双重验证的账户，还需完成页面要求的一次性验证码或恢复验证。
4. 登录成功后进入控制台，检查当前账户与平台公告。

不要在共享设备上保存密码。离开前主动退出账户；怀疑设备泄露时，在其他可信设备撤销相应登录会话。

## 注册账户

1. 从登录页进入注册，填写用户名、密码与确认密码。
2. 平台要求邮箱验证时，填写可接收邮件的邮箱，发送并输入验证码。
3. 完成人机验证和协议确认后提交。
4. 按页面结果登录；如果注册关闭，向管理员申请账户。

邮件未收到时检查垃圾邮件及平台允许的邮箱域名。不要向他人提供验证码，也不要频繁重复发送。

## Passkey 与第三方登录

选择登录页实际显示的登录方式。第三方登录需在对应服务完成授权；Passkey 按浏览器或设备提示验证。没有显示的方式不代表账户故障，可能是平台未启用。

首次关联前确认第三方账户身份。已登录账户的绑定与解绑在“安全与访问”中进行，注意保留可用的登录方式。

## 忘记密码

在登录页选择“忘记密码”，提交账户绑定邮箱。收到重置邮件后打开链接，设置新密码并重新登录。链接失效时重新申请，以最新页面提示为准。

收不到邮件或没有可用恢复方式时联系管理员；不要把重置链接转发给他人。

## 登录后检查会话

前往“安全与访问” → “登录会话”，确认当前及其他设备。撤销不认识的会话；撤销当前会话后需要重新登录。会话撤销与 API 密钥停用是不同操作，异常访问时要分别检查。
