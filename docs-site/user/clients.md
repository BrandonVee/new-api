# 聊天应用集成

将支持相应协议的聊天客户端连接到开明能源 Token 中转站。客户端必须支持自定义服务地址；客户端会员不等于平台 API 权益。

## 通用配置步骤

1. 在平台创建该客户端专用的 API 密钥。
2. 在客户端选择与模型相符的供应商或 OpenAI 兼容协议。
3. 填写管理员提供的平台 Base URL 和自己的 API 密钥。
4. 手动填写或刷新实际可用模型，保存后发送一条简短消息。
5. 回到平台“使用日志”核对这次调用。

## 三个字段怎样对应

| 客户端字段 | 填写内容 | 常见错误 |
| --- | --- | --- |
| API Host／Base URL | 平台 API 地址，是否加 `/v1` 取决于客户端 | 填成当前文档站地址或重复拼接路径 |
| API Key | 当前用户的模型 API 密钥 | 填成账户密码、PAT 或上游密钥 |
| Model | 平台允许的精确模型名称 | 使用客户端默认但平台未开放的模型 |

不要仅凭模型名判断协议支持。客户端发送图片、工具调用或文件前，应确认目标模型、渠道与客户端均支持该能力。

## 平台内聊天入口

管理员可配置聊天应用链接或预设。打开前确认目标地址与所需凭据，特别留意是否跳转外部服务。仅向可信客户端提供密钥，不要把密钥包含在分享链接中。

## 连接后仍然失败

先用 [最小 API 示例](/user/playground) 判断问题是否只出在客户端，再检查客户端代理、协议、最终路径与模型名。提交排障材料时移除密钥和个人对话内容。

更多配置原则见 [通用客户端配置](/integrations/clients)；自行开发见 [Python、Node.js 与服务端](/integrations/code)。
