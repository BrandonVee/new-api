# 模型广场与排行榜

模型广场帮助你选择平台已公布的模型和价格；数据看板中的排行帮助你了解实际调用分布。这两种信息不能相互替代。

## 查找模型

打开平台模型价格页面（`/pricing`），按名称、供应商、分组、接口类型或标签等可用条件筛选。可切换列表或卡片视图，打开模型详情查看说明。

## 调用前核对

| 信息 | 核对重点 |
| --- | --- |
| 模型名称 | API 请求使用精确名称，不按展示昵称自行拼写 |
| 接口类型 | 客户端与平台支持的协议一致 |
| 分组与价格 | 选择自己可用的分组，确认计价单位 |
| 能力说明 | 文本、图片、工具等能力以实际接入情况为准 |

展示某模型不保证当前账户可调用，也不保证所有渠道支持其全部参数。首次调用使用短请求验证；报无可用渠道时联系管理员。

## 查看排行榜

当前项目的数据看板提供“调用数量排行”等视图，位置见 [概览与数据看板](/user/dashboard)。它反映选定时间与权限范围内的调用数据，不是公开模型能力榜，也不代表效果或性价比推荐。

如果平台另外配置了外部排行榜入口，以页面标注的数据来源和更新时间为准；本指南不假设该入口已经启用。

## 价格与实际消耗

注意价格单位、分组和适用规则。页面价格用于理解定价，实际消耗应结合使用日志及生效权益核对，不要只按回复字数估算。余额或套餐问题见 [钱包与订阅](/user/wallet)。
