# 配额、钱包与订阅

钱包用于查看余额、充值与订阅权益。账户权益和 API 密钥限额共同约束调用，不能只检查其中一个。

## 查看钱包

打开“钱包”（平台 `/wallet`），查看平台实际开放的余额、充值、账单与订阅区域。显示单位与换算方式由平台配置决定，请按页面标注核对。

| 对象 | 作用 |
| --- | --- |
| 钱包余额或账户额度 | 账户可消费的权益 |
| 订阅计划 | 在有效周期内按计划提供的权益与限制 |
| API 密钥额度 | 限制某个应用的可用预算 |

## 配额不足与补足

遇到额度不足时，先检查密钥额度和有效期，再检查钱包余额、订阅状态及所选分组。钱包还有余额，也可能因密钥限额或分组限制无法调用。

平台允许时可通过充值、兑换码或购买合适的计划补足；未开放线上支付时联系管理员，不要向未核实的收款方付款。

## 充值与兑换

1. 在钱包选择平台提供的充值方式，核对金额、单位与订单说明。
2. 在可信支付页面完成支付，返回后查看余额和账单记录。
3. 使用兑换码时输入完整代码并提交，查看兑换结果与余额变动。
4. 已付款未到账时先检查订单状态，保留订单号与时间联系管理员，避免重复付款。

兑换码可能有状态、期限和适用限制，以提交结果为准。不要公开分享未使用的兑换码。

## 选择订阅计划

阅读计划说明，核对价格、有效期、额度或重置周期、可用分组以及购买限制，再确认购买。不要仅凭套餐名称推断权益。

购买后检查已生效的订阅记录。是否允许续购、叠加、自动续费或与余额共同使用，以当前平台和支付页面的说明为准；本指南不承诺默认支持。

## 核对消耗与账单

使用相同时间范围查看使用日志与钱包记录。异步任务可能在提交后继续处理，客户端超时并不代表一定退款。有争议时提供订单或任务 ID，由管理员核对最终记录。

管理员维护计划请阅读 [订阅计划管理](/admin/subscriptions)。
