# 概览与数据看板

“概览”用于快速了解账户与使用情况；“数据看板”用于按时间和模型分析调用趋势。普通用户与管理员的可见数据范围不同。

## 查看账户概况

1. 登录后打开“概览”（平台 `/dashboard/overview`）。
2. 查看页面提供的账户摘要、平台公告和接入信息。
3. 需要核对账户权益时进入“钱包”；需要查某一次请求时进入“使用日志”。

页面为空时先确认是否已有调用，再检查时间范围和平台是否开放相关模块。

## 分析模型用量

打开“数据看板”（平台 `/dashboard/models`），选择时间范围和统计粒度。当前界面支持按小时、天或周查看，并提供调用趋势、调用数量分布和调用数量排行等图表。

| 你想了解 | 查看方式 |
| --- | --- |
| 哪段时间调用较多 | 调用趋势与时间范围 |
| 哪些模型调用最多 | 调用数量排行或分布 |
| 某次请求为什么失败 | 使用日志中的对应记录 |
| 费用是否与预期一致 | 相同时间范围的用量、钱包与结算日志 |

统计排行表示当前可见数据中的调用情况，不是模型质量评测。比较前保持时间范围、用户范围和单位一致。

## 常见问题

数据与客户端统计不同，先检查时区、筛选条件、统计延迟和失败请求是否纳入统计。异步任务可能稍后完成，费用以最终记录为准。

对某个异常点，记录时间和模型，在 [使用日志](/user/logs) 中查明细后再联系管理员。
